# GraphicCalculator
A graphical user interface (GUI) calculator that performs addition, subtraction, multiplication, and division  using Python's Tkinter library.

Simple Tkinter Calculator:

A lightweight graphical calculator built with Python and Tkinter. Performs basic arithmetic operations with input validation and error handling.


Features:

Addition, subtraction, multiplication, and division.

Input validation — shows error messages for non-numeric values.

Division-by-zero protection.

Clear button to reset all fields.

Fixed-size, user-friendly interface.

Built with standard Python libraries only — no external dependencies.


Requirements:

Python 3.10+ (uses match statement)

Tkinter — included with standard Python installations on Windows, macOS, and most Linux distributions.


Installation & Usage:

Clone or download this repository.

Save the code as calculator.py.

Run the script:

bash:

python calculator.py

Enter two numbers in the input fields.

Click any operation button to see the result.

Click Clear to reset both inputs and the result display.


Error Handling:

Non-numeric input: Shows pop-up error → "Enter a valid number."

Division by zero: Displays → "Cannot divide by zero."
